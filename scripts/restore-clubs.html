Club restore

Reads a running SRIDHAR RUSH server's memory and prints the SQL that rebuilds your clubs.

  1. Leave the game server alone — do not redeploy or restart it. Its memory is the copy we are reading.
  2. Paste your game server's address below (the one the site talks to).
  3. Press Read the live server, then Copy the SQL.
  4. Paste that SQL into the Supabase SQL Editor and press Run.
What comes back: each club's name, tag, motto, badge, colour, weekly and lifetime metres and points — exactly. Each member's own distance comes back to the nearest 0.1 km, keyed by the display name the roster shows (the public API never exposes account ids), and the game re-attaches real identities the next time each racer joins or races.

If the list you get back has only the game's own clubs (Redline Motorsport, Akina SpeedStars, Midnight Club Tokyo, Veloce Grand Prix, Monza Oversteer Works), the server has restarted since the purge and its memory no longer holds your clubs — stop here and use a Supabase backup instead.
