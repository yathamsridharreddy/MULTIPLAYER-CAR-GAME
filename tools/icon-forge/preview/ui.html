What changed here: these icons replace emoji, which are font glyphs — so the old UI was drawn by whatever emoji font the visitor's device had (Apple / Segoe / Noto) and showed as an empty ☐ box on devices missing the codepoint. These are real SVG files, so they look identical everywhere and are coloured by the stylesheet instead of by the OS.
